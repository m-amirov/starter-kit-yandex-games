# Migration 0.4.0 — Production Skill Stack

> Safety notice: do not use the 0.4.0 updater for a mature project. Use the
> target-aware 0.4.1 updater and read
> `migrations/0.4.1-target-aware-updater.md`. The guidance below remains the
> historical production-skill migration record.

## Purpose

Adds five externally informed Yandex-specific adaptations and seven production skills without changing game rules or automatically rewriting project-owned files.

## Managed files

Updater may safely import `.codex/skills/`, `config/skill-policy.json`, precedence/source documents, starter-kit tooling and core contracts when unchanged locally.

## Manual project integration

1. Merge the new authority order into the project's root `AGENTS.md` or local skill system.
2. Preserve any more specific Yandex/Cloud Save/ads/release procedures already present.
3. Add relevant fields from `game-spec.yaml` without replacing the project's product data.
4. Connect skill evidence paths to the existing release audit.
5. Do not enable PWA, service workers, CDN assets, autoplay or WebGPU-only rendering.
6. Run skill-policy self-test and targeted project regressions.

## Release impact

This migration does not itself require gameplay or art changes, but subsequent release candidates must satisfy the new applicable production gates.
