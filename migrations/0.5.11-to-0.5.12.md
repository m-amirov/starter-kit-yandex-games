# Migration: Starter Kit 0.5.11 → 0.5.12

Only an **optional** story-promise reference checker is added for future
visual novels and interactive fiction. Existing Yandex games keep all runtime,
SDK, content, visuals, localization and save behavior unchanged.

1. Keep the project's stored target profile and skill root. Start with
   `node tools/starter-kit/apply-update.mjs --target <existing-game> --dry-run`.
2. Review conflicts using the existing semantic/managed ownership rules.
   Do not force-update product-owned files or accept all conflicts.
3. Future projects can copy the disabled managed `narrative-game` profile
   to a project-owned path, explicitly set `enabled:true`, and optionally
   add `promisesPath` to a game-derived ledger JSON.
4. If `promisesPath` is absent, the old graph/save checks are unchanged.

The checker proves only declared scene, guard and route-reference consistency,
not emotional payoff, actual runtime evidence or commercial reader engagement.
Nothing activates a new release gate.
