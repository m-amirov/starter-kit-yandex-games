# Starter Kit 0.5.4 → 0.5.5

Version 0.5.5 updates release validation to the official numbered requirements revision of 18 August 2026 and adds the Console-only first-publication horizontal gameplay-video gate. It also includes explicit incoming semantic resolution introduced for this release.

## Safe mature-project integration

1. Run `apply-update.mjs --profile mature-yandex-phaser --dry-run`.
2. Review semantic proposals for `config/yandex-requirements.yaml`, `config/yandex-console-requirements.yaml`, `docs/YANDEX_REQUIREMENTS_CHECKLIST.md`, `AGENTS.md` and `package.json`.
3. Preserve project-owned `game-spec.yaml`, runtime, assets, package lock and product contracts. Add `yandex.publication.type` and the horizontal gameplay-video marketing contract to the project-owned spec by semantic review; the updater must not rewrite it.
4. Accept managed validation tools, schemas, skill changes and the gameplay-video task template through the configured single `skillRoot`.
5. Run targeted Yandex validation tests, updater/idempotency tests and the full Starter Kit self-test.

`--resolve-semantic <logical-id>` continues to accept and record the current project version of a semantic conflict. Use `--resolve-semantic-incoming <logical-id>` only after explicit review when the incoming Starter Kit version should replace the conflicting semantic or target-mapped target. `package.json` remains accept-current only so project scripts and dependencies stay authoritative.

## Behavioral changes

- Requirement 1.12 now accepts ads-only or IAP-only monetization and blocks when neither exists.
- Repealed numbered clauses remain `repealed`/`obsolete` traceability records.
- `CONSOLE-FIRST-PUBLICATION-HORIZONTAL-GAMEPLAY-VIDEO` blocks only first publication.
- Media validation proves file/container, dimensions, aspect, duration, size, metadata and SHA-256; real gameplay share and visual/locale content remain manual evidence gates.
- Promotional MP4 files are forbidden in the game ZIP.

This migration adds no game runtime dependency and does not change gameplay, balance, Yandex SDK runtime integration or project-owned assets.
