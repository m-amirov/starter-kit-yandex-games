# Starter Kit 0.5.13 -> 0.5.14

Additive opt-in VK Games distribution profile (VKontakte and Odnoklassniki, not VK Play).

- Default enabled=false; no Yandex runtime or release contract replacement.
- Shipped manifest entries: disabled profile template, VK build/QA checker, reference adapter, example contract and docs.
- Existing game-owned runtime, package lock, bundler, assets and save schema remain untouched.
- A game must independently provide VK SDK integration, platform-specific build and real-client evidence.
- Static PASS_VK_STATIC_CONTRACT never implies releaseReady. --release requires game HEAD, build SHA256 and complete live-client matrix.
- Run updater --dry-run first; review semantic merges for package/scripts and policy and re-run Yandex gates for affected targets.
