# Starter Kit 0.5.5 → 0.5.6

Version 0.5.6 adds a controlled semantic watch for current official Yandex Games documentation. It extends the existing requirements audit, Yandex release validation, independent release audit and target-aware updater; it does not add a parallel engineering framework.

## Mature-project update

1. Start from a clean project worktree and run `apply-update.mjs --profile mature-yandex-phaser --dry-run`.
2. Review the proposed managed watcher files, snapshot, skills and checklist. Resolve existing semantic contracts through the updater's normal explicit conflict flow.
3. Apply the update and run `npm run yandex:requirements:audit`, `npm run yandex:console:audit` and the offline Starter Kit suites.
4. Run `npm run yandex:docs:check` when network integration evidence is required. Do not accept a changed snapshot until the concrete diff is reviewed and the affected registries/tests are green.

The mature profile continues to preserve `game-spec.yaml`, `src/`, `public/`, runtime, evidence and product assets. The update does not create another skill root, overwrite product-owned seeds, add game runtime dependencies or place documentation tooling in the production bundle.

## Release behavior

- Unresolved semantic changes block packaging/pre-submit with `BLOCK_YANDEX_DOCS_CHANGED_REVIEW_REQUIRED`.
- Parser drift and unclassified changes fail closed.
- `FETCH_FAILED` requires explicit manual review of the current canonical documents and is not PASS.
- `yandex:docs:accept-snapshot -- --reviewed-at YYYY-MM-DD --policy-reviewed` is the explicit action for semantic policy changes; it records reviewed registry hashes and never edits requirements registries.
